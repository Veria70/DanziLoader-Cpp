# M4.7d: draws with console shaders made by the driver (GFX10 code in the
# console's container layout, signature parts), translated by the
# reference's translator into the shader cache the port reads (its own
# translations: tools/check_own_translations.py, milestone 5). Pipelines
# from streams (rasterizer, depth, input layout,
# target formats); targets through their views; viewports and scissors;
# a depth test against cleared depth; vertices from a vertex buffer; the
# console's rectangles (three corners, the fourth made: by the reference's
# geometry stage or on the CPU, the same for a vertex shader that passes
# its input on); an indexed draw. Every target read back and hashed.
runtime
shader_cache c:/tmp/m4-shader-cache c:/tmp/m4-shader-cache/build.bin
create_device dev device11
create_queue dev q 0
create_fence dev f 0
allocator dev a 0
list dev l 0 a
list_close l
desc_heap dev views 0 4096 flags=1
desc_heap dev rtvs 2 8
desc_heap dev dsvs 3 8
committed dev back 3 B1048576
committed dev rt 1 T3/64x64/f28/F1
committed dev dp 1 T3/64x64/f40/F2
committed dev vb 2 B65536
committed dev ib 2 B4096
rtv dev rtvs:0 rt
dsv dev dsvs:0 dp
vs_fullscreen vs
vs_input vsi
ps_color ps 1.0 0.5 0.25 1.0
ps_color ps2 0.0 1.0 0.0 1.0
graphics_pipeline dev g vs ps 28
graphics_pipeline dev gd vs ps2 28 depth=40
graphics_pipeline dev gi vsi ps2 28 input
