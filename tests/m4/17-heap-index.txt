# M4.12: shaders that pick resources from the view heap by an index they
# compute (SM 6.6 dynamic resources). The driver's console shaders load a
# descriptor at 32 * (a root constant) from the heap's address: a raw buffer
# view (cs_heap) or a texture (cs_heap_tex). Nothing in their tables names
# what they read, so the host makes every buffer view of the heap ready
# once a frame (and the stride table by slot), and uploads the textures the
# title fills that sit in the heap. What the title writes into such a
# buffer later in the same frame is seen a frame late (the reference's
# shortcut), then seen. A draw in a new frame runs the texture pass early
# (no shader of it picks by index), so that a later dispatch finds its
# texture there without a buffer pass.
